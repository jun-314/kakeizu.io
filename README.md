# 家系図ドラフター

**家系図**と**年齢管理**の2つのタブを持つ、ビルド不要の静的サイト。
GitHub Pages にそのまま置けます。

- **家系図タブ** — 人物を選ぶと、周囲のカードにその人から見た**親等**（血族／姻族）が表示されます
- **年齢管理タブ** — リストごとに人物と生年月日を登録し、年齢と次の誕生日を自動計算します

## 家系図タブ

- **自動整列** — 世代を確定し、夫婦をひとまとまりにして子の中央に親を揃えます。夫婦は男性が左、きょうだいは年長が左。カードは個別にドラッグでき、「自動整列」でいつでも整形し直せます
- **親等の自動判定** — 民法の数え方（直系を遡ってから下る単調経路）で血族・姻族を区別し、`父` `兄` `伯父` `甥の配偶者` などの呼称も自動生成します
- **旧姓** — 旧姓を保持し、カード表示と絞り込みの両方で使えます
- **フィルタ** — 検索・姓・性別・故人・「選択した人物からn親等以内」
- **サイズ調整** — カードの大きさと文字の大きさを別々に変更できます
- **書き出し／読み込み** — JSON（再読込可）と SVG（印刷・作図用）。旧形式（`parents` / `spouses` / `children` を持つ配列）の JSON も読み込めます
- 編集内容はブラウザの localStorage に自動保存されます

## 年齢管理タブ

- **「家系図」リストは家系図タブと自動連動** — 家系図に人物を追加・編集・削除すると、そのまま年齢管理にも反映されます。コピーではなく家系図の人物をそのまま参照しているので、二重管理は起きません
  - 行をクリックすると家系図タブへ移動し、その人物を選択した状態で表示します
  - 新規登録の「追加先」で **家系図** を選ぶと、家系図タブにも人物として追加されます（続柄はあとから家系図タブで設定します）
  - 故人は既定で非表示。「故人も表示」をオンにすると**享年**と没年を添えて並びます（平均年齢・最年長・最年少の集計は常に存命者のみ）
- **自分のリスト** — 家系図に載せない人（職場・サークルなど）は、通常のリストを作って管理できます。「すべて」では両方が横断表示され、どのリストの人かはバッジで分かります
- **自動計算** — 年齢、次の誕生日までの日数、平均年齢、最年長・最年少。当日は「本日 誕生日」と表示されます
- **並べ替え** — 誕生日が近い順／年下から／年上から
- **入力** — 年・月・日は候補リストから選ぶことも、直接入力することもできます。月に応じて日の候補が変わります
- **書き出し／読み込み** — 端末間で移せる文字列コード（Base64）と JSON ファイル。旧アプリのデータ（`age-app-data-v1`）は同じドメインなら自動で引き継ぎます

「家系図」リストの実体は家系図タブ側にあるため、年齢管理の書き出し／読み込みの対象外です。
家系図のデータは家系図タブの「データ」から入出力してください。

## 構成

```
kakeizu-drafter/
├── index.html          … ページ本体（マークアップのみ）
├── assets/
│   ├── style.css       … 全スタイル（配色トークン・ライト／ダーク対応）
│   └── app.js          … アプリ本体（依存ライブラリなし）
├── .nojekyll           … GitHub Pages の Jekyll 処理を無効化
└── README.md
```

外部から読み込むのは Google Fonts（Zen Kaku Gothic New / Shippori Mincho / JetBrains Mono）だけで、
オフラインでもフォールバック書体で動作します。

## GitHub Pages への公開

1. このフォルダの中身をリポジトリの直下に置いて push します

   ```bash
   git init
   git add .
   git commit -m "家系図ドラフター"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```

2. GitHub のリポジトリで **Settings → Pages** を開く
3. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして Save
4. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

サブフォルダに置く場合（例：リポジトリ直下の `kakeizu-drafter/`）は
`https://<ユーザー名>.github.io/<リポジトリ名>/kakeizu-drafter/` になります。
`index.html` からの参照はすべて相対パスなので、どちらでも修正は要りません。

## ローカルで開く

`index.html` をブラウザにドラッグするだけで動きます。
簡易サーバーで確認する場合は次のとおりです。

```bash
python -m http.server 8000
```

## 操作

| 操作 | 内容 |
|---|---|
| `1` `2` | 家系図タブ／年齢管理タブの切り替え |
| カードをクリック | 選択（周囲に親等を表示） |
| カードをドラッグ | 個別に移動 |
| 背景をドラッグ | 全体を移動 |
| ホイール／ピンチ | 拡大・縮小（カーソル基準） |
| `+` `-` | 拡大・縮小 |
| `0` | 全体表示 |
| `F` | 自動整列 |
| `Delete` | 選択中の人物を削除 |
| `Esc` | 選択解除・ダイアログを閉じる |

スマートフォンでは、指1本でドラッグ＝移動、2本指のピンチ＝拡大縮小です。
右パネルは画面下から出るシートになり、既定では閉じた状態で開きます（ツールバー右端のボタンで開閉）。

## データ形式

```jsonc
{
  "people": [
    { "id": "p1", "surname": "山田", "given": "源蔵", "maiden": "",
      "gender": "male",            // male | female | other
      "birth": "1928-03-04",       // 1928 / 1928-03 のように精度を落としても可
      "death": "2009-11-18", "deceased": true, "note": "" }
  ],
  "unions": [
    { "id": "u1", "partners": ["p1", "p2"],   // 片方が null なら単親
      "children": ["p3", "p4"],
      "status": "married" }                    // married | partner | divorced
  ],
  "pos": { "p1": { "x": 0, "y": 0 } },         // 手動配置（省略可）
  "set": {}                                    // 表示設定（省略可）
}
```

年齢管理タブの「自分のリスト」は別形式です（「家系図」リストは上の家系図データから毎回組み立てるため、
保存も書き出しもされません）。

```jsonc
[
  { "id": "g1", "name": "マイリスト",
    "people": [
      { "id": "m1", "name": "山田 太郎", "dob": "1985-08-30",
        "createdAt": "2026-09-06T00:00:00.000Z" }
    ]
  }
]
```
